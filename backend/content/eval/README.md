# Planner eval set (lane A1)

- `labels.json`: 26 videos labelled by hand before the classifier was run. Labels come from the
  English captions (`python -m app.planner.evaluate view <id>`), with storyboard frames checked where
  the captions were unclear (`frames <id> <s>`). The set has 11 tutorials (Python ×3, JavaScript,
  Java, C, C++, C#, SQL, React, PyTorch), 4 theory videos (Abdul Bari ×2, OOP, dynamic programming),
  3 mixed (Fireship Python/Go, CS50 lecture 0), 3 code-mentioning non-tutorials (Lex Fridman with
  Guido, Karpathy's LLM talk, 3Blue1Brown on neural networks) and 5 non-coding videos (2 songs,
  3 talks, 1 math visualisation). Long videos are labelled and classified only for their first
  40 min (`labelledUntilS`). 4 instructor challenges are labelled with their answer time.
- `results.json` / `results-run2.json`: two independent runs of the live classification path
  (`claude-haiku-5-5`, answer-on-screen check on, no exercise generation).
- `REPORT.md`: generated by `python -m app.planner.evaluate score content/eval/results.json content/eval/results-run2.json`.
- `captions/`, `frames/`: local caches, gitignored.

## Result (2026-11-08)

| | Run 1 | Run 2 |
| --- | --- | --- |
| Section "qualifies" precision | **0.918** (78/85) | **0.962** |
| Section "qualifies" recall | 0.876 | 0.874 |
| Time-weighted precision / recall | 0.935 / 0.866 | 0.944 / 0.818 |
| Video verdict (coding vs not_coding) | 24/26 | 23/26 |
| Pauses in labelled teaching, before a labelled answer | 77/78 | 0.974 |

Precision is at least 0.9 in both runs, so the bar is met and auto-pause can be on. The 95% lower
bound on run 1 is 0.84, so the margin is small for 85 sections.

## What goes wrong

- **False positives** (7 in run 1) all fall at the same boundary: the "create a project and run
  Hello World" section of a beginner tutorial (Java, C, C++, C#, Python, plus JS "run with node" and
  React "install Bootstrap"). The labels count IDE/project setup as not qualifying. No section of a
  non-coding or code-mentioning video was ever marked as qualifying in either run.
- **Recall misses**: the SQL course's first 40 min (database theory and keys, no SQL typed yet)
  came back `not_coding` in both runs. 3Blue1Brown's neural-network structure (labelled as
  computable theory) was `not_coding` in both. Python in 100 Seconds was `not_coding` in run 2.
  Short recap/outro sections near teaching account for the rest. The classifier leans toward
  leaving playback alone, which is the intended failure mode.
- **Wrong pause**: C++ at 729.7 s ("print a line with cout") sits in the project-setup section
  (same boundary as above). Run 2 also has one at 753.7 s in the C course for the same reason.
- **Hard labels** (judgement calls): Abdul Bari's intro ("algorithm vs program", labelled not
  qualifying, classifier agrees), 3Blue1Brown's neural network (labelled qualifying), Fourier
  transform (labelled not qualifying, classifier agrees).

## Limits

- One labeller. Labels are segment-level, and a section's truth is the majority of its labelled time.
- Pause correctness only checks placement (inside teaching, and for `question_posed` pauses, before
  a labelled answer). It does not grade the generated exercise.
- Only the first 40 min of long videos (one classifier window) are covered.
